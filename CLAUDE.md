## Overview

This is a personal website and blog built with Hugo, a static site generator written in Go. The site uses the "Bear Cub" theme and is deployed to GitHub Pages automatically via GitHub Actions.

## Site Architecture

### Content Structure
- `content/` - All site content in Markdown format
  - `_index.md` - Homepage content
  - `w/` - Blog posts/writings directory
    - Contains personal essays, thoughts, and updates
  - `apps.md`, `music.md`, `now.md`, `study.md`, `work.md` - Main section pages
- `static/assets/` - Static assets (images, etc.)
- `layouts/shortcodes/` - Custom Hugo shortcodes
  - `anki-stats.html` - Renders Anki study statistics with pure CSS/HTML visualizations
- `themes/hugo-bearcub/` - Git submodule containing the Bear Cub theme
- `data/` - Data files consumed by Hugo
  - `anki_stats.json` - Exported Anki statistics (generated by script)
- `scripts/` - Utility scripts
  - `export_anki_stats.py` - Exports Anki data from local database to JSON

### Configuration
- `hugo.toml` - Main Hugo configuration file
  - Site uses "hugo-bearcub" theme
  - Configured for stefanmiko.com domain
  - Syntax highlighting enabled without inline styles
  - Social card generation enabled

## Common Development Commands

### Local Development
```bash
# Start development server with live reload
hugo server

# Start server with drafts included
hugo server -D

# Start server on different port
hugo server -p 8080
```

### Building
```bash
# Build the site for production
hugo --gc --minify

# Build with different base URL
hugo --baseURL "https://example.com/"

# Build including draft content
hugo -D
```

### Content Management
```bash
# Create new blog post
hugo new w/post-title.md

# Create new page
hugo new page-name.md
```

### Theme Management
```bash
# Update theme submodule
git submodule update --remote themes/hugo-bearcub
```

### Anki Stats Management
The `/study` page displays Anki study statistics using data exported from the local Anki database.

```bash
# Export latest Anki statistics
python3 scripts/export_anki_stats.py

# This will:
# 1. Find and read your Anki database (usually at ~/Library/Application Support/Anki2/)
# 2. Extract review history, card stats, and forecast data
# 3. Generate data/anki_stats.json for Hugo to consume
```

**Important**: Run the export script before deploying to update the statistics on the live site. The GitHub Actions workflow does not have access to your local Anki database, so stats must be exported manually and committed to the repository.

## Deployment

The site is automatically deployed to GitHub Pages via GitHub Actions workflow (`.github/workflows/hugo.yaml`) when changes are pushed to the main branch. The workflow:
1. Installs Hugo CLI (v0.128.0) and Dart Sass
2. Checks out code with submodules
3. Builds the site with `hugo --gc --minify`
4. Deploys to GitHub Pages

## Content Guidelines

### Front Matter Format
All content files use TOML front matter:
```toml
+++
title = 'Page Title'
date = 2024-08-25T21:20:14+02:00
menu = 'main'  # Optional: adds to navigation
weight = 1     # Optional: menu ordering
+++
```

### Writing Style
- The site has a personal, minimalist aesthetic
- Uses botanical/flower symbols (✿, ❀, ✳, ❁, ❂, ❆) as section dividers
- Content is organized as a "digital garden" with organic growth metaphors
- Blog posts in `/w/` directory cover personal topics, tech, and life updates

## Theme Customization

The Bear Cub theme configuration includes:
- Original theme style (not Herman variant)
- Dynamic social card generation
- Email reply functionality enabled
- Accessible color palette and typography
- No JavaScript, minimal CSS for performance
